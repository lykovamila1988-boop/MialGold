# 🤖 Автономный цикл публикации Telegram контента

## Описание

Полностью **автоматизированный и автономный** процесс создания и публикации контента в Telegram канал Людмилы Лыковой.

**Работает без участия человека 24/7.**

---

## 🚀 Запуск

### Способ 1: Scheduler (рекомендуемый)

```bash
# Запустить scheduler - будет работать бесконечно
# Ежедневно в 00:30 запускает полный цикл
cd mila-office
python scheduler_autonomous.py --mode schedule
```

Scheduler будет автоматически запускать цикл каждый день в одно и то же время.

### Способ 2: Один раз (для тестирования)

```bash
# Запустить цикл один раз (займёт ~5 минут)
python autonomous_daily_loop.py
```

### Способ 3: n8n webhook (если n8n запущен)

```json
{
  "trigger": "Schedule - 00:30 every day",
  "action": "POST http://localhost:5000/api/autonomous/daily-loop",
  "body": {}
}
```

## 📁 Файлы система

### Входные файлы

- **tools/.env** — конфигурация
  - `TELEGRAM_CHANNEL_ID=-1003005733230` (публичный канал)
  - `TELEGRAM_BOT_TOKEN=...` (бот для публикации)
  - `ANTHROPIC_API_KEY=...` (Claude API для агентов)

### Выходные файлы (логи)

```
logs/
├── telegram_daily_metrics.jsonl    # Ежедневная статистика канала
├── telegram_trends.json            # Определённые тренды
├── daily_forecast.json             # План на завтра
├── daily_autonomous_log.jsonl      # Полный лог цикла
└── [date]_posts.json              # Опубликованные посты с Message IDs
```

## 💡 Как система сама себя развивает

### День 1
- Olya видит что вчера хорошо работали инсайты (8.3% engagement)
- Marina создаёт 3 инсайта на сегодня
- Tyoma публикует - engagement растёт
- Rita подготавливает завтра "больше инсайтов"

### День 2
- Olya видит что инсайты работают хорошо, кейсы хуже
- Marina баланс: больше инсайтов, меньше кейсов
- Tyoma публикует с новым балансом
- Rita: "вечернее время лучше для практик"

### День 3+
- Система автоматически адаптируется к предпочтениям аудитории
- Нет человека который говорит "напиши больше инсайтов" - система сама видит тренд
- Контент эволюционирует на основе реальных данных

**Это не статический контент - это живая система которая учится и адаптируется.**

## ⚠️ Когда система работает автономно

✅ **Она может работать сама по себе:**
- Создавать посты
- Публиковать посты
- Анализировать метрики
- Адаптироваться к трендам
- Готовить планы на завтра

❌ **Её может остановить:**
- Лимит API (если Claude API упадёт)
- Проблема с Telegram API
- Человек изменит конфиг или остановит scheduler

## 🔍 Мониторинг работы
